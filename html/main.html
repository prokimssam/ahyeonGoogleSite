Curriculum Flow

edit_note

Game Planning

7시간/주

독창적인 아이디어 구상부터 시스템 설계 및 밸런싱을 아우르며 공모전 제출을 위한 공식 게임 기획서를 완성합니다.

code

Game Programming

7시간/주

C#을 기반으로 유니티 6와 고도 엔진을 배웁니다. AI 도구를 활용한 바이브 코딩으로 프로토타입을 초고속으로 빌드합니다.

palette

Computer Graphics

6시간/주

포토샵과 일러스트레이터를 활용하여 게임에 필요한 2D 그래픽 원화 소스, UI/UX 에셋 및 스프라이트 시트를 제작합니다.

movie_filter

Media Content General

6시간/주

캡컷으로 직접 만든 게임의 트레일러 영상을 편집하고, 노션 아카이빙을 통해 나만의 차별화된 포트폴리오를 구축합니다.
